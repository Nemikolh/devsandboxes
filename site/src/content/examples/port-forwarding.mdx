## The problem

An agent started a dev server on port 3000 inside instance `api` and you want it in your browser, or `psql` on your host against that instance's Postgres. Publishing ports with `-p` has to happen at create time, collides as soon as a second instance wants the same port, and can't reach a server listening on the container's `127.0.0.1`.

`devsandbox port` forwards a port **on demand**, like VS Code's _Ports_ tab: it is on `localhost` until you stop it.

<AgentPromptLink />

## Config

Forwarding needs no config; any sandbox works. This one has a service to forward to as well:

```toml title="config.toml"
[services.postgres]                 # one per instance, no `ports` needed
image = "postgres:16"
env = { POSTGRES_PASSWORD = "postgres" }

[sandbox.api]
folder = "../api"
image = "node:22"
services = ["postgres"]
postCreateCommand = "npm install"
```

## Try it

```bash
devsandbox run api
devsandbox exec -it api bash       # inside: npm run dev -- --port 3000
```

In another host terminal (runs until Ctrl-C):

```bash
devsandbox port api 3000                        # http://localhost:3000
devsandbox port api 8080:3000                   # host :8080 -> api's :3000
devsandbox port api --service postgres 5432     # api's own postgres
```

- `--service`: forward a service's port instead of the instance's.
- `--address`: the host address to bind (default `127.0.0.1`).

From the dashboard: `p` on an instance or service, type the port; live forwards are on the **Ports** tab (`3`). To have the dashboard forward a port whenever the instance runs, add `forwardPorts = [3000]` to the sandbox ([`forwardPorts`](/docs/config#implemented-devcontainer-properties)).

## How it works

- Each connection is tunnelled through the in-container helper, so a server on the container's `127.0.0.1` is reachable and nothing is published.
- `--service` goes through a running instance that uses the service ([services](/docs/config#services-servicesname)).
- A bare port taken on the host falls back to the next free one; the printed line says which.
- Unix hosts, TCP only.
